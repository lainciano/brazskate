# Braz Skate

Site institucional do **Campeonato Braz Skate**, organizado pela
**ASB — Associação Skate Brazlândia** (Brazlândia/DF). Next.js + TypeScript,
100% estático (SSG), sem backend, hospedado na Vercel.

Contexto completo, decisões e especificação do site: `docs/01-CONTEXTO.md`,
`docs/02-DECISOES.md` e `docs/03-SPEC-SITE.md`.

## Rodar localmente

```bash
nvm use        # alinha a versão do Node (ver .nvmrc)
pnpm install
pnpm dev        # http://localhost:3000
```

Outros comandos: `pnpm build`, `pnpm lint`, `pnpm typecheck`.
